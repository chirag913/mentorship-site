Which tier should I pick?

Take the fit check and it'll recommend one. Rule of thumb: Start if you don't know what you'd sell yet, Build if you want the system set up and ready to send, Full if you want me with you all the way to a signed client. Already experimented? The First Client Sprint skips straight to outreach. Pick what you can comfortably afford.

What do the tools cost?

Start doesn't need any paid tools. Once outreach starts, it's about ₹12–13k a month: Instantly (~₹5k), Apollo (~₹4–5k), Claude Code (~₹2k) and a workspace mailbox (~₹1k), plus ₹1–2k one-time for domains. Paid separately — not part of the mentorship fee. That's why every tier shows an all-in number.

I've already tried this. Do I have to start from week 1?

No. The First Client Sprint is built for you: 6 weeks, starting from the niche and offer you already have, going straight to infrastructure, outreach, calling and closing. ₹30,000, or 2 × ₹15,000.

Can I pay in instalments?

Yes. The Sprint can be paid as 2 × ₹15,000. For Build or Full, message me on WhatsApp and we'll set up a split that works.

I have zero experience. Can I really do this?

Yes. I built this to start from scratch: niche, offer, tools, outreach, closing, in that order. If you've never done any of this, you're exactly who it's for.

Do I need to know how to code?

No. It's all no-code tools. You're learning to use them, not build them from scratch.

What if I already have a skill or clients?

You'll fly through the first couple of weeks and spend most of your time on the acquisition side.

Have you actually used this yourself?

Yes — I use this exact system in my own agency right now, and for actual clients. It's not a course I put together and never tested.

Is this guaranteed to work?

No, and I won't pretend otherwise. I'll teach you the system and help you build it. What you do with it after that is on you.
